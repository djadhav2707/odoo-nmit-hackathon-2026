The Challenge & Our Solution

Bridging the gap between employee empowerment and administrative control

Problem vs Solution

❌ Traditional HR Inefficiencies

  • Fragmented portals causing attendance discrepancies.
  • Slow, manual email-based leave request approval chains.
  • Opaque payroll calculations and delayed salary slip delivery.
  • Vulnerable security without strict single-admin governance.

✅ The Dayflow Advantage

  • Real-time 1-Click Punch: Instant check-in/out tracking with effective working hours.
  • Interactive Leave Queue: Instant manager approval/rejection with real-time balance update.
  • Automated Payroll Engine: Transparent CTC, HRA, PF & tax deduction receipts.
  • Role-Guarded Architecture: Strict ADMIN001 gatekeeping with zero employee escalation.

🔐 100% Secure Auth

4-step OTP account recovery & strict single-admin credential validation.

⚡ Live Real-Time Sync

New employee onboarding reflects across the portal instantly.

🎨 Unified Design Tokens

Human-centric Wine/Rose palette with Fraunces serif branding.

React 19 Frontend + Vite: Componentized layouts, stateful punch clock, dynamic avatars.
Vite Proxy & Express 5: Zero-CORS routing to /api/* and /employees endpoints.
MongoDB Atlas + Memory Fallback: Live data persistence with demo resilience.
